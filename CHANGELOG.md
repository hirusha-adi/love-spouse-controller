## Earlier tags

The historical `v1` and `v2.0` tags both predate the F-Droid preparation.
The Gradle version at `v2.0` is `1.0` with version code `1`; those tags do not
match the app's version name. Future tags follow `v<versionName>` and every
release increases `versionCode`.
